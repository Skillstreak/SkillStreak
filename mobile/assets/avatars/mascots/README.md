# Sportmaskotar för Sportbyn (I-004)

Tio transparenta djurfigurer, arenornas ansikte i Sportbyn. De är INTE spelaravatarer:
de ingår inte i `AVATAR_CATALOG` (väljaren O3) utan i `SPORT_MASCOTS`.

## Filer (20 st)
- `<id>.png`: 256x256 (1x). `<id>@2x.png`: 512x512 (2x). Metro väljer storlek själv.
- Kvadratiska, PNG med alfa. Originalen är passade in i kvadraten utan beskärning.
- id: bear_rugby, eagle_skiing, hare_floorball, kangaroo_volleyball, lion_basketball,
  moose_hockey, otter_rowing, owl_tennis, panda_skateboard, raccoon_golf.
- Hela uppsättningen måste finnas, annars kraschar Metro-bundlingen.

## Krav
- Inga loggor, inga kända dräkter eller märken, ingen text i bilden.
- Inga ringar, emblem eller andra skyddade symboler (se Juridiks varumärkesanalys 2026-11-02).
- Filnamn och alt-text får inte innehålla företags-, sponsor-, arena- eller tävlingsnamn.
- Före butiksinlämning: granska bilderna med ögonen mot ljus och mörk bakgrund.
